## How to Replace Images

### Method 1: Direct Replacement (Easiest)
1. Navigate to the appropriate folder in `assets/images/`
2. Delete the placeholder image
3. Add your professional photo with the **exact same filename**
4. Refresh the browser

### Method 2: Update HTML References
If you want to use different filenames:
1. Add your new image to the appropriate folder
2. Open the relevant HTML file
3. Find the `<img src="...">` tag
4. Update the `src` attribute to your new filename
5. Update the `alt` attribute for accessibility

### Example: Replacing Wedding Hero Image
```html
<!-- Before -->
<img src="assets/images/hero/hero-1.jpg" alt="Luxury Event Decoration">

<!-- After (if using new filename) -->
<img src="assets/images/hero/our-wedding-showcase.jpg" alt="Herkinx Events luxury wedding decoration at Grand Hotel Lagos">
```

## Optimization Checklist

Before deploying, optimize all images:

- [ ] Compress with TinyPNG or ImageOptim (target <200KB per image)
- [ ] Use WebP format with JPG fallback for better performance
- [ ] Add proper `alt` text for all images (SEO + accessibility)
- [ ] Test lazy loading works (images load as user scrolls)
- [ ] Verify mobile images aren't too large (consider responsive images)

### Responsive Images Example
```html
<picture>
  <source srcset="assets/images/hero/hero-1.webp" type="image/webp">
  <img src="assets/images/hero/hero-1.jpg" alt="Luxury Event Decoration" loading="lazy">
</picture>
```
