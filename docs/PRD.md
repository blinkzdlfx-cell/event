# PRD - Herkinx Events Website

## Project Overview
Herkinx Events is a luxury event decoration company website designed to showcase premium event decoration services and convert visitors into clients.

## Business Objectives
- Establish Herkinx Events as a premium luxury event brand
- Generate booking inquiries through the website
- Showcase portfolio and services elegantly
- Build trust through testimonials and professional presentation

## Target Audience
- Individuals planning events
- Couples (weddings, engagements)
- Families (birthdays, anniversaries)
- Corporate organizations
- Churches and schools
- Event planners seeking decoration partners

## Core Features (Demo Version)

### 1. Home Page
- Hero section with luxury headline and CTA buttons
- About preview section
- Services preview
- Featured portfolio gallery
- Statistics counter
- Testimonials carousel
- Booking CTA
- Instagram feed preview
- Footer with contact info

### 2. About Page
- Company story and mission
- Team introduction
- Values and philosophy
- Why choose Herkinx Events

### 3. Services Page
- Elegant service cards
- Detailed service descriptions
- Service categories
- Learn more functionality

### 4. Portfolio Page
- Luxury image gallery
- Category filtering (Weddings, Birthdays, Corporate, etc.)
- Fullscreen image viewing
- Before/after comparisons

### 5. Testimonials Page
- Client testimonials
- Star ratings
- Event type badges

### 6. FAQ Page
- Common questions and answers
- Accordion style display

### 7. Contact/Booking Page
- Comprehensive booking form
- Form fields: Name, Phone, Email, Event Type, Date, Venue, Guest Count, Budget, Notes
- Success message display (demo mode)
- Contact information

### 8. Chat UI Placeholder
- Floating chat button
- Chat window interface
- Message input
- Demo mode response
